# ADR-001: Single-process layered desktop monolith with a pure core

- **Status:** ACCEPTED
- **Feature:** wallcovering-takeoff
- **Requirements:** FR-7, NFR-1, NFR-2, NFR-3

## Context

The tool serves one estimator working one drawing set per run with no distribution requirement, but must support an interactive edit-and-recompute loop, an on-screen drill-down and a live review queue. A localhost service split and a headless CLI pipeline were both evaluated.

## Decision

Build one desktop process in layers: DesktopShell (Qt) over TakeoffPresenter over the domain services, with TakeoffEngine as a pure I/O-free core and ProjectRepository as the only persistence boundary. No local HTTP service, no separate deployable.

## Consequences

Positive: no serialization hop inside the recompute loop, one artifact to package and debug, offline by construction, and layer boundaries that a review bot can check by inspecting imports. Negative: no multi-user or web path without later introducing a transport boundary; the math core is reachable only from Python without an added interop layer; layer separation depends on import discipline rather than process isolation.
