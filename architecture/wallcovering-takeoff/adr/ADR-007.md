# ADR-007: Per-WC unit fidelity with no cross-unit conversion path

- **Status:** ACCEPTED
- **Feature:** wallcovering-takeoff
- **Requirements:** FR-2, FR-5, FR-6

## Context

Commercial goods sell by the linear yard off a bolt and residential goods by the roll, and a single set can mix both. Any generic conversion helper invites an aggregate view that blends incompatible units into a meaningless total.

## Decision

UnitOfSale is read per WC from that WC's own schedule row and travels with QuantityResult and TakeoffLine. The codebase exposes no linear-yard-to-roll conversion function, and the aggregate view lists each WC in its own unit with no combined total.

## Consequences

Positive: AC-5.3 holds by construction and a mixed-unit set cannot produce a blended figure. Negative: there is no single scalar summarising the whole order, which some users may expect.
