# ADR-005: Flag rather than guess, with blocking flags gating computation

- **Status:** ACCEPTED
- **Feature:** wallcovering-takeoff
- **Requirements:** FR-8, FR-2, FR-3, FR-4

## Context

Missing ceiling heights, undefined WC tags, unresolved blanket-note overrides, unknown match types and plan-versus-elevation conflicts are all normal conditions in a real set. Substituting a plausible default would produce a confident, wrong order quantity that no downstream check could detect.

## Decision

FlagRegistry owns a review queue; any missing, ambiguous or contradictory input raises a typed Flag recording its source sheet and what it blocks. TakeoffEngine consults blocking_flags_for before computing, and a TakeoffLine with a non-empty blocked_by emits no quantity at all rather than a partial or estimated one.

## Consequences

Positive: no fabricated quantity can reach an order line, and every gap is visible with its provenance. Negative: an incomplete set yields an incomplete takeoff, which is correct but places real review burden on the estimator before numbers appear.
