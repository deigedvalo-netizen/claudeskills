# ADR-012: Every computed number is registered in a trace ledger

- **Status:** ACCEPTED
- **Feature:** wallcovering-takeoff
- **Requirements:** NFR-1, FR-7

## Context

NFR-1 forbids black-box totals and requires each displayed number to be traceable to its formula and source dimensions, and the output design requires drill-down from an order line to per-wall drop math.

## Decision

GeometryService, TakeoffEngine and AggregationService each register a TraceRecord for every value they produce, carrying the formula as displayed, the named inputs consumed and a source reference per input. The presentation layer resolves any displayed value through explain_value, and a displayed value that cannot be resolved is treated as a defect rather than rendered bare.

## Consequences

Positive: AC-7.1 and AC-7.2 are served by one mechanism, and review bots can assert that every rendered figure resolves. Negative: computation carries a bookkeeping cost and the ledger must be invalidated and rebuilt on every edit-triggered recompute.
