# ADR-008: Rooms model an explicit wall set; wall-level tags override room-level defaults

- **Status:** ACCEPTED
- **Feature:** wallcovering-takeoff
- **Requirements:** FR-3, FR-8

## Context

Blanket notes such as ALL WALLS: WC-1 combined with per-wall exceptions are the normal way finishes are documented, and a back-wall accent may appear with no blanket note at all. Resolving this by text interpretation alone is ambiguous.

## Decision

Model each Room as an explicit set of Wall records. A room-level blanket note sets a default across that set, a wall-level tag replaces the default for that wall only, and each Application records its origin as ROOM_BLANKET, WALL_OVERRIDE or ELEVATION_TAG. Any room whose resolution is ambiguous raises UNRESOLVED_UNO and is not guessed.

## Consequences

Positive: AC-3.1 and AC-3.2 fall out of the model directly, and origin provenance makes conflicts explainable. Negative: the wall set must be established for every room before applications can resolve, which adds entry work for rooms with a single tagged wall.
