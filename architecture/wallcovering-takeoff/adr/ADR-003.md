# ADR-003: Deterministic exact arithmetic via Decimal in a pure math core

- **Status:** ACCEPTED
- **Feature:** wallcovering-takeoff
- **Requirements:** FR-5, FR-6, NFR-2

## Context

The quantity math is dominated by ceil operations at boundaries (drops, repeat-rounded cut length, rolls). Binary floating point can place a boundary value on either side of an integer step, so the same inputs could yield a different roll count across runs or machines, breaking NFR-2.

## Decision

TakeoffEngine is a pure module with no I/O, no clock, no randomness and no global state, operating on Decimal under an explicitly set context. All rounding to a sale unit is round-up, intermediate areas are never rounded down, and raw and with-waste figures are both retained rather than one being derived for display.

## Consequences

Positive: byte-identical results across runs and platforms, and the core is trivially testable in isolation by the downstream test stage. Negative: Decimal is slower than float and every call site must avoid accidental float coercion, which becomes a standing review check.
